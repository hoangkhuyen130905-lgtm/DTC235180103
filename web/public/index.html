Các Câu Lệnh Truy Vấn LogQL Mẫu (Loki)

Mở Grafana > mục Explore > chọn nguồn dữ liệu Loki và sử dụng các query sau:

1. Lọc tất cả log của Nginx Reverse Proxy:
{job="nginx"}
2. Lọc các request gặp mã lỗi HTTP (4xx hoặc 5xx):
{job="nginx"} |~ "HTTP/[0-9.]+ (4|5)[0-9]{2}"
3. Lọc log ứng dụng web có chứa keyword "borrow":
{job="library-web"} |= "borrow"
4. Tính tốc độ log per second theo thời gian:
rate({job="nginx"}[1m])
